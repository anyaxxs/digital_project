# Анализ осанки человека по фото

Учебный цифровой проект по нейронным сетям. Программа получает фотографию человека, находит ключевые точки тела с помощью модели YOLO Pose и рассчитывает признаки осанки.

Для фото спереди рассчитываются:

- наклон плеч;
- наклон таза;
- смещение головы относительно центра плеч;
- наклон корпуса относительно вертикали.

Для фото сбоку рассчитываются:

- выдвижение головы вперед;
- наклон шеи;
- наклон корпуса;
- смещение плеча относительно таза.

Важно: результат не является медицинским диагнозом. Это демонстрация практического применения нейронной сети для анализа изображения.

## Что нужно для работы

1. Установить Python 3.10 или новее.
2. Открыть папку проекта в терминале.
3. Создать виртуальное окружение:

```bash
python -m venv .venv
```

4. Активировать окружение:

```bash
source .venv/bin/activate
```

На Windows команда будет другой:

```bash
.venv\Scripts\activate
```

5. Установить библиотеки:

```bash
pip install -r requirements.txt
```

6. При первом запуске YOLO автоматически скачает небольшой файл модели `yolo11n-pose.pt`.

## Как подготовить фото

- человек должен быть виден в полный рост или хотя бы от головы до таза;
- камера должна быть примерно на уровне середины тела;
- желательно светлый фон и хорошее освещение;
- человек должен стоять ровно, без сумки и верхней одежды, которая скрывает плечи;
- можно использовать фото спереди или сбоку: программа автоматически выберет подходящий набор показателей.

## Как запустить

Положите фото в папку проекта, например `photo.jpg`, и выполните:

```bash
python posture_analyzer.py photo.jpg
```

Не добавляйте `--backend mediapipe`, если специально не настраивали MediaPipe отдельно. Основной рабочий режим проекта - YOLO Pose.

После запуска появится папка `results`. В ней будут:

- `photo_posture.png` - фотография с разметкой тела;
- `photo_report.txt` - текстовый отчет;
- `photo_report.json` - структурированный отчет с числами.

Можно указать свою папку для результатов:

```bash
python posture_analyzer.py photo.jpg --output-dir my_results
```

## Что показать в проекте

В исследовательской части можно объяснить, что нейронная сеть YOLO Pose находит ключевые точки тела: нос, уши, плечи, таз, колени и другие. Затем программа использует координаты этих точек и рассчитывает углы и смещения.

В практической части можно показать:

- исходное фото;
- фото с разметкой;
- таблицу показателей из отчета;
- вывод о том, какие признаки осанки программа нашла;
- ограничения метода: результат зависит от качества фото, позы человека, одежды и положения камеры.

## Как улучшить проект

- собрать датасет из нескольких фотографий с разными позами;
- добавить сравнение фото "до" и "после";
- сделать веб-интерфейс;
- добавить сравнение боковой фотографии "до" и "после";
- обучить собственную модель классификации: "ровная осанка", "есть отклонения", "сильные отклонения".
